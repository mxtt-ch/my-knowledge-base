### 6.3 代码示例规范（300+行）
```cpp
// 示例：代码标题
// 功能说明：这段代码演示了...
// 关键点：注意...
// 适用场景：...
// 性能考虑：...

#include <iostream>
using namespace std;

int main() {
    // 第1步：变量声明和初始化
    int x = 10;  // 声明变量x并初始化为10
                 // 类型：int (通常 4 字节)
                 // 作用域：当前块
                 // 生命周期：直到块结束
    
    // 第2步：输出操作
    cout << "x = " << x << endl;  // 输出x的值
                                  // endl 等价于 '\n' + flush
                                  // 刷新输出缓冲区
    
    return 0;  // 返回 0 表示程序成功执行
}

/*
 * 输出结果：
 * x = 10
 * 
 * 代码解析：
 * 1. #include <iostream>：包含输入输出流库
 *    - 提供 cout, cin, cerr 等对象
 *    - 定义在 std 命名空间中
 * 
 * 2. using namespace std：使用标准命名空间
 *    - 避免每次都要写 std::cout
 *    - 注意：大型项目中不推荐全局 using
 * 
 * 3. int main()：程序入口点
 *    - 返回类型必须是 int
 *    - 操作系统通过返回值判断程序状态
 * 
 * 4. return 0：正常退出
 *    - 0 表示成功
 *    - 非零值表示错误
 * 
 * 扩展思考：
 * - 如果去掉 return 0 会怎样？
 *   C++ 标准规定 main 函数隐式返回 0
 * 
 * - 为什么不用 void main()？
 *   这是非法的，main 必须返回 int
 */
```
